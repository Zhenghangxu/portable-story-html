## Install

```bash
npx skills add Zhenghangxu/portable-story-html --skill portable-story-html
```

## Source of truth

Do not edit the mirrored skill files in this repository. The canonical files live in [`Zhenghangxu/shared_skills/portable-story-html`](https://github.com/Zhenghangxu/shared_skills/tree/main/portable-story-html).

The `Sync skill from shared_skills` GitHub Actions workflow mirrors that directory here daily and can also be run manually.
